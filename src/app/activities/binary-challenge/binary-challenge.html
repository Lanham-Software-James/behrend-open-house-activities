What does this have to do with computer science?

Each switch is a bit: a 0 or a 1. From right to left, each position is worth twice as much as the last. Add the values of the bits that are on to get your number. With eight bits, you can represent any whole number from 0 to 255.

For example, 86 = 64 + 16 + 4 + 2. Computers use these same binary building blocks to represent information.
